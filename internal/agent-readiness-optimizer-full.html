Findable across AI platforms

Each assistant finds websites in its own way: through its own search crawler, a regular search index (Google or Bing), or by visiting a page when someone asks. This table checks your robots.txt and the page's robots meta tags against the crawlers each company publishes. xAI publishes none for Grok, so its row can only be checked against your catch-all rule. Training crawlers are listed separately: blocking them is your choice and doesn't stop answers, except Google-Extended, which also controls Gemini's answers.

What the audit can't see

Assistants also rely on search indexes, business listings and directories. Tick these off as you confirm them. Saved in this browser.

    Ask each assistant yourself

    Copy the question, ask it in each assistant without naming your organization, and record what happened. Repeat every few months: answers change as indexes update.

    Test with a live agent

    Claude reads only what an agent would get from this page (its text and links, with no JavaScript run) and tries to help a person. A question passes when the agent sends them to your main action link or phone. Start a line with ! for a request you can't help with: it passes when the agent doesn't send that person to your main action.
